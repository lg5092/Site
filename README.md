# Louiggi Gaitan — Personal Portfolio

This is my personal portfolio website. I created this site to showcase a few of my personal and school projects. Above is the link to the site. On my site, I linked the source code or live links of projects on the cards below. 

## Features

- **Intro**: profile picture and links to my GitHub, email, and LinkedIn
- **About Me**: a short summary of my interests
- **Skills & Technologies**: shown as a set of tags
- **Projects**: clickable cards that link to live demos or source code
- **Animations**: a fade-in on load and a hover effect on the cards

## Tech Stack

- Next.js: framework 
- TypeScript: web development logic
- Tailwind CSS: styling
- Framer Motion: animations
- Lucide: photo icons
- shadcn/ui:  component setup

## Project Structure

```
src/
├── app/
│   ├── layout.tsx      # Root layout: fonts, metadata, global styles
│   ├── page.tsx        # Home page: all portfolio content
│   └── globals.css     # Tailwind and global styles
└── components/
    └── ui/             # Reusable UI components (button, card)
public/                 # Images (profile photos) and static assets
```
